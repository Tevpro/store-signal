# Security and responsible disclosure

Do not post vulnerabilities, exploit details, credentials, private browsing data or customer content in public issues. Contact `rick@tevpro.com` privately with reproduction steps and a safe impact summary. This repository currently contains plans only; no production checker or deployed security boundary has been established. Required release reviews include SSRF, redirects/DNS rebinding, extension scope, prompt injection, BYOK key encryption, tenant isolation, rate-limit concurrency, public allegations and correction tooling.
