# Contributing

Start with `AGENTS.md`, `docs/requirements.md`, `docs/architecture.md`, and `docs/coding-standards.md`. Put reusable/nontrivial models, types and schemas in separate descriptively named files; name implementation files for the behavior they contain rather than only the API version (`v1/` may be a folder). Simple one-off output types may remain local. Choose an unclaimed GitHub issue; link the matching Plane card for internal work. Discuss contract changes before implementation. Use one scoped PR targeting main and include actual test output, security/privacy considerations, and rollback. No screenshots, customer data, account keys, unlicensed copied review corpora or opaque AI verdict fixtures.

This public planning repository has no software license yet. Until an approved license and contribution terms are published, please open issues/discussions rather than submitting code you expect others to reuse. Maintainers will not merge third-party code contributions while licensing is unresolved.
